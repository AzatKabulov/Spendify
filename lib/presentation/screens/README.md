# `presentation/screens/`

Full-page Flutter widgets, one folder or file per screen. Presentational only — no business logic, no direct repository or Hive calls. Screens read state from Riverpod providers and call provider/repository methods for actions.

Roadmap: home (Phase 2), add/edit transaction (Phase 2), categories + budgets (Phase 3), reports (Phase 4), auth (Phase 5), receipt scan + confirm (Phase 7), gamification surfaces (Phase 8), advice (Phase 9), consent + settings (Phase 10).

Usability target (from Phase 2): a first-time user saves their first transaction in under 60 seconds — visible add button on home, sensible defaults, only amount + category mandatory.
